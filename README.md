# Wedding Invitation Website

A Vercel-ready Next.js + TypeScript wedding invitation website for C. Jefron Vasanth and S. Anshiya.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run start
```

## Deployment

This project is ready to be deployed to Vercel without any additional setup.

## Editable details

The event information and Google Maps links are defined in `app/page.tsx` and can be adjusted directly there.
